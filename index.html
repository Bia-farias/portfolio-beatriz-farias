Transformando ideias em interfaces interativas e eficientes

Olá! Sou Beatriz Farias, natural de Caracol-PI e residente em São Paulo-SP. Minha trajetória prática é construída através do desenvolvimento de projetos reais, aplicando as tecnologias mais modernas do ecossistema front-end.

Especializo-me no desenvolvimento de aplicações com React 18, TypeScript, Tailwind CSS e JavaScript (ES6+), integrando produtos digitais a APIs REST, serviços em nuvem com Supabase, modelos de IA generativa (Groq AI) e testes unitários com Vitest.

Prezo por código limpo, semântica acessível (A11y), arquitetura escalável e design ergonômico no Figma, garantindo que cada interface proporcione a melhor experiência aos usuários finais.
