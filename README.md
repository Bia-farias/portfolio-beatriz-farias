## ✨ Principais Funcionalidades

- **Design Moderno & Dark Theme**: Interface com estética elegante, acentos vibrantes, efeitos de luz (*glow effects*) e estética *glassmorphism*.
- **Efeito de Digitação Interativo (Typing Effect)**: Apresentação animada com alternância dinâmica de papéis e especialidades.
- **Totalmente Responsivo**: Layout fluido e adaptado com abordagem Mobile-First para smartphones, tablets e desktops.
- **Menu Mobile Interativo**: Navegação suave com menu hamburger animado.
- **Seção Sobre Mim**: Resumo de jornada profissional, objetivos e caixas de destaque em experiência, educação e metodologias.
- **Cards de Habilidades Técnicas**: Barras de progresso animadas e visualização clara de competências em HTML5, CSS3, JavaScript ES6+, React e Git/GitHub.
- **Formulário e Links de Contato**: Acesso direto para envio de mensagens, redes sociais e conexões profissionais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível, otimizada para SEO e com boa arquitetura da informação.
- **CSS3 Moderno**: Layout estruturado com Flexbox e CSS Grid, animações suaves (`keyframes`), variáveis nativas (`CSS Custom Properties`) e microinterações.
- **JavaScript ES6+**: Manipulação do DOM, controle de rolagem suave (*scroll smooth*), botão dinâmico de retorno ao topo e efeito de digitação sem dependências externas.

## 💻 Como Executar Localmente

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/Bia-farias/portfolio-beatriz-farias.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio-beatriz-farias
   ```

3. **Abra no seu navegador preferido:**
   - Basta abrir o arquivo `index.html` com dois cliques, ou
   - Usar a extensão **Live Server** no Visual Studio Code para recarregamento automático.
